## هدف
افزودن یک دکمه یک‌کلیکی در سایدبار سایت که کاربر را به ریپوی GitHub پروژه می‌برد تا فایل ZIP کل کد را دانلود کند.

## پیش‌نیاز کاربر
چون کد سورس روی سرور Lovable است و در مرورگر در دسترس نیست، باید پروژه ابتدا به GitHub متصل شود:
- در Lovable: دکمه + کنار چت → GitHub → Connect project → ساخت ریپو.
- بعد از اتصال، آدرس ریپو (مثلاً `https://github.com/USERNAME/REPO`) را به ما بده تا در دکمه قرار دهیم.

## تغییرات کد

### ۱) `src/components/AppLayout.tsx`
- اضافه کردن آیکون `Download` از `lucide-react`.
- اضافه کردن یک ثابت در بالای فایل:
  ```ts
  const GITHUB_REPO_URL = "https://github.com/USERNAME/REPO"; // بعد از Connect پر می‌شود
  const GITHUB_ZIP_URL = `${GITHUB_REPO_URL}/archive/refs/heads/main.zip`;
  ```
- در انتهای `nav` (بعد از `otherNavItems.map`) یک دکمه جدید با استایل مشابه `NavItem` اضافه شود:
  - متن: «دانلود کد (ZIP)»
  - زیرعنوان کوچک: «از GitHub»
  - `onClick`: باز کردن `GITHUB_ZIP_URL` در تب جدید (`window.open(..., '_blank')`).
  - آیکون: `Download` با gradient ملایم primary→accent برای هماهنگی با بقیه سایدبار.

### ۲) بدون تغییر در منطق
هیچ تغییری در دیتابیس، احراز هویت یا state اپ ایجاد نمی‌شود — فقط یک لینک خروجی است.

## نکات
- اگر برنچ پیش‌فرض ریپو `main` نباشد (مثلاً `master`)، در URL همان نام جایگزین می‌شود.
- اگر ریپو private باشد، دانلود ZIP نیاز به لاگین کاربر در GitHub دارد (محدودیت خود GitHub، نه کد ما).
- اگر بعداً خواستی، می‌توانم یک Modal راهنما هم اضافه کنم که اگر کاربر هنوز GitHub را متصل نکرده، مراحل اتصال را نشان دهد.

## سوال قبل از اجرا
لطفاً آدرس ریپوی GitHub پروژه و نام برنچ اصلی (`main` یا `master`) را بفرست تا لینک دکمه دقیق ست شود.
